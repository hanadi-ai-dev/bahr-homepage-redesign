## Typography and ownership

The official website uses Ataero. This implementation uses self-hosted, open-source Space Grotesk and Noto Sans Arabic, plus a system serif italic for selected editorial words. It does not redistribute the official site's proprietary font file. Font licenses are included in `docs/licenses/`.

Bahr's mark, official copy, and project imagery are credited to Bahr and the respective project owners, and are included in this independent challenge redesign. They are not original portfolio work by the submitter. The interface composition, contour field, and motion code are original to this submission.

## GSAP guidance

Implementation patterns were researched from the official https://github.com/greensock/gsap-skills repository, particularly `gsap-core`, `gsap-timeline`, `gsap-scrolltrigger`, and `gsap-performance`. These informed registration, master timeline sequencing, context/matchMedia cleanup, responsive pinning, reduced-motion handling, `quickTo`, and off-screen work suspension. No example site's creative composition was copied.
